# PSD2UIForm AI 整理 UI 设计记录

状态：需求访谈中，尚未确认完整设计或开始实现。

## 已确认的需求

- 在 PSD2UIForm 中新增公共组件抽取能力，参考 PSDLayoutTool2。
- 公共组件抽取不同于已有的公共 Prefab 导出与 refp 引用。
- 使用 skill 指导 AI 分析，生成可校验的整理与抽取方案。

## 第一轮确认

用户已确认以下边界：

1. 首版支持结构不同的重复组件，以公共部分和状态分组表达差异；覆盖前六天单奖励、第七天多奖励的签到场景。
2. 从 PSD 重新生成时，保留新增脚本、事件绑定和手工覆盖；与 PSD 更新冲突时展示冲突，不直接覆盖。
3. 抽取的公共 Prefab 默认放在当前界面旁的 Common 目录。跨界面共用时再明确提升为全局组件。

## 待确认的交互建议

- 将现有 AI 识别入口升级为统一的 AI 整理 UI 窗口，后台复用 CLI，并保留可选终端日志。
- 一次分析包含类型识别、功能层级整理与公共组件建议；用户审阅后应用。
- 将抽取规则持久化，在最终 UI 生成时创建公共 Prefab 与嵌套实例。

## 当前未决问题

- 结构差异的状态分组是否需要运行时切换能力。
- 重新生成发现冲突时，是否阻止整次生成并保持原资产不变。
- 统一入口的方案预览和用户修正方式。

## 验收方向

- 公共组件实例保留各自图像、文字、布局和选定状态。
- 再次生成保持公共资产身份与实例引用，并保护手工修改。
- AI 结果通过节点身份、快照与操作合法性校验后才允许应用。
- 所有逻辑保持通用，不能按特定测试资产名称编写规则。
