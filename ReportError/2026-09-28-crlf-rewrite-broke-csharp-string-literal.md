# 用脚本批量改写 CRLF 文件时破坏了 C# 字符串里的 `\n`

- 日期：2026-09-28
- 现象：批量删除 v1 残留时，用 Python 重写 CRLF 换行的 C# 测试文件后 Unity 编译失败。
- 原因：换行符转换把 C# 字符串字面量里的转义序列 `\n` 当成了真实换行写回文件，字符串被截成两行，导致语法错误。

## 下次避免

- 修改 C# 源码优先用 Edit 工具做精确替换，不要用脚本整体读写再做换行替换。
- 必须脚本处理时，以二进制方式读写并只替换目标文本，不要对全文做 `\r\n`/`\n` 互转。
- 改完立即 `unity command recompile` + `recompile_status`，确认 0 错误后再继续。
