# 01: 手动抽取同结构组件并生成真实嵌套实例

**Status:** done

**Blocked by:** 无。

**Scope:** 本轮实现独立手动入口，操作已保存的生成后 UI Prefab。PSD 编辑节点、重生成规则及统一 AI 窗口属于后续工单。

交付：用户选择一组同结构组件，输入名称，预览并应用固定抽取方案，生成当前界面 Common 中的公共 Prefab 和对应实例。

- [x] 最小操作入口、方案校验、生成及重新加载验证形成闭环，不依赖 AI。
- [x] 保留不同图片、文字、颜色、布局和排序；原位置成为真实嵌套实例。
- [x] 无效成员、交叉引用及输出冲突在写入前报告。
- [x] 未执行抽取的旧生成流程不变；取消预览不修改资产。

## 使用

打开生成后的 UI Prefab，保存修改，多选同结构组件根节点，然后使用 `Tools > PSD2UIForm > 抽取公共 Prefab…`（或 Hierarchy 右键对应菜单）。输入公共组件名、预览并应用，输出至当前界面的 `Common/`。

按子节点顺序和组件类型对应结构，保留实例 UI 属性及内部引用；不复制 Unity 内部编辑器隐藏标志。已有嵌套实例、跨选区引用、不同结构、未保存修改和同名输出均拒绝处理。当前不支持重新从 PSD 生成后恢复规则；不要在仍需重生成的正式界面上依赖这一能力。
