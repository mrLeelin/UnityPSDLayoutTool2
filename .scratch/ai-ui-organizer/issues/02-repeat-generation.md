## 实现与使用

1. 在已保存的 PSD 编辑 Prefab 中生成 UI，界面旁保存 `界面名.extraction.asset` 来源记录。
2. 手动抽取时追加公共资产 GUID 和实例 GlobalObjectId。规则资产按目标 GUID 查找，移动文件后仍可识别。
3. 再次生成前校验来源 GUID、编辑树/PSD/配置指纹及真实嵌套关系。输入不变时直接保留已保存的资产图，不重建对象，避免改动 GUID、local file ID 和外部引用。
4. 来源改名、重排、删除、生成目标更名/迁移、实例解包、身份丢失等均在生成前报告冲突，不猜测节点映射。

旧版输出及无持久来源的场景仍支持01的手动抽取，但窗口明确提示不能保证 PSD 重复生成；需要先从已保存的编辑 Prefab 生成新 UI 以建立来源，再抽取。不提供旧规则自动迁移，也不支持从丢失的目标资产重建实例。
