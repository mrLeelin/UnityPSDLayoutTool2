# 工单03：不同结构抽取

## 使用方法

1. 打开生成后的 UI Prefab，保存当前修改。
2. 在 Hierarchy 多选要共用组件的区域根节点，例如普通奖励区和双奖励区。
3. 打开 `Tools > PSD2UIForm > 抽取公共 Prefab…`，填写公共组件名称。
4. 勾选“不同结构（保留各自形态）”，点击“预览当前选区”。
5. 检查公共成员、各 State 分支的成员及每个来源对应的默认分支，再点击“应用预览方案并保存”。

公共资产保存在当前 UI Prefab 旁的 `Common` 文件夹。窗口会重新打开原界面，每个选区已替换为公共资产实例。普通模式的行为保持不变。

## 规则与边界

- 根组件类型一致时保留根组件；只合并子节点序列开头连续、同名且结构对应的子树，保留其原顺序。后续差异成员进入状态分支，图片、文字等值仍属于各实例覆盖。
- 根组件类型不同时保留每种完整根子树，用中性 RectTransform 承载实例位置。公共列表可以为空。
- 状态按结构归类，各实例只有自己的分支启用；不增加运行时切换脚本。
- 状态显示和实例覆盖保存在 Prefab 中；沿用02的来源规则与实例稳定身份验证，同输入生成保留整个保存的资产图。源更新合并仍属于04。
- 已有嵌套 Prefab、跨抽取边界引用、根节点自动布局等不支持的输入在预览阶段拒绝。不会根据签到素材的节点名字匹配生产数据。
- 对自定义脚本依赖字符串路径、运行时遍历层级的行为未作兼容保证；自动测试覆盖序列化 UI 属性与对象引用。
